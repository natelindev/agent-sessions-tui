# Agent Sessions identity

Stacked terminal session windows, with the active session illuminated and ready to resume.

SVG marks use paths and scale without a font dependency. PNG exports have transparent backgrounds. Use `mark-dark` on dark surfaces and `mark-mono` for one-color reproduction. Preserve the 64-unit square and keep at least 8 units of clear space. Wordmark SVGs use system sans text; PNG wordmarks are fixed exports. The favicon adapts to the system color scheme. Assets are covered by the repository license.
